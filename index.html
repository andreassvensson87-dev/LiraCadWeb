    VÄLKOMMEN TILL LIRACAD

    Hitta ditt ritflöde.

    Dubbelklicka på text för direktredigering. Enter ger ny rad och Ctrl/⌘+Enter sparar. Skriv annars direkt i ritytan. Kommandoraden lyssnar när du inte redigerar ett textfält.

    Rita

    L Linje · PL Polylinje · REC Rektangel
    C Cirkel · A Båge (3 punkter)
    T Text · LE Hänvisning · HA Skraffering

    Redigera

    M Flytta · CO Kopiera · RO Rotera
    SC Skala · MI Spegla · O Offset
    E / Delete Radera · TR / EX Trimma / förläng · DI Mät
    J / X Sammanfoga / dela upp · PI / PD Hörnpunkter
    F / CHA Fillet / Chamfer
    DLI / DAL / DAN / DRA / DDI / DCO Måttsättning
    MV Viewport i layout · PSPACE Till papper

    Navigera & välja

    Styrplatta: två fingrar panorerar, nyp zoomar.
    Välj Mus i statusraden för hjulzoom.
    Håll mittenknappen eller Space + dra för panorering.
    Klicka för att välja, Shift för flerval.
    Dra åt höger: inneslutna objekt.
    Dra åt vänster: även korsande objekt.

    Exakta värden

    100,200 Absolut punkt
    @100,50 Relativ punkt · @500<45 Polar
    Efter startpunkt: skriv längd i musens riktning.
    Decimalpunkt i koordinater; decimalpunkt eller komma för enstaka tal.

    F3: objektsnapp. F10: Polar med valt vinkelsteg. F11: Track — stanna över en snappunkt för att fånga en referens, följ sedan hjälplinjen. F8: Ortho. Första utgåvan: lokal projektlagring och DXF-export. DWG/DXF-import finns med rapport över förenklingar. Offset stöder linjer, raka polylinjer, cirklar och bågar. Enter avslutar polylinje/skraffering; Esc avbryter. Dra en markerad linjes ändpunkt för att ändra den.
